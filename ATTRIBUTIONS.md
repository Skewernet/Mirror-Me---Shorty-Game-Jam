# Assets and dependencies

- Three.js **0.160.1**, including the unmodified Reflector addon: Copyright © 2010–2023 Three.js authors, MIT license. Local distribution in `vendor/`; full license in `vendor/THREE-LICENSE.txt`. Retrieved from the version-pinned jsDelivr npm distribution over verified HTTPS. https://github.com/mrdoob/three.js/tree/r160
- Game-specific geometry, surfaces and interface are created within this project. No P.T. assets or external fonts are used.
- All seven voice clips are synthetic provisional performances produced offline using the public-domain LJ Speech dataset voice model distributed by sherpa-onnx. See `assets/voice/MODEL_CARD.txt` and `assets/voice/README.md` for provenance and generation details. No human actor performance is represented.
- Wallpaper, timber, runner, landscape painting, note textures and all game geometry are generated by original project code. Footsteps, hum, air, knocks, drawer and key sounds are synthesized in Web Audio; no external sound library is included.
- House expansion material atlas and paired family photographs are original AI-generated assets created for this project. The people pictured are fictional. Source PNGs are in `assets/art/`; surfaces are sampled from the atlases by the runtime. No P.T. imagery or photography of a real family is used.
- `vendor/RoundedBoxGeometry.js` is the unmodified Three.js 0.160.1 addon, covered by `vendor/THREE-LICENSE.txt`.
